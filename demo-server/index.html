Lief

Detection test hub

Served from localhost, which is allowlisted — so this page never fires a banner, and is itself a negative control.

Before you start Open chrome://extensions → Lief → service worker. That console is the only place detection failures show up. Every link below opens in a new tab so this hub stays put.

Should fire

The banner appears at the top of the page. Read the detail sentence — that string is the product.

  • http://paypa1.com:8080/login.html dangerous

    H1 · lookalike-domains. The hero case. Detail must name the digit 1 where the letter l belongs — not "suspicious domain". This page also carries a password field, so H3 fires behind it.

  • http://arnazon.com:8080/login.html dangerous

    H1 · lookalike-domains. A different fold rule: r and n side by side reading as a single m. Proves the explanation is generated, not hardcoded.

  • http://login.google.com.secure-verify.ru:8080/login.html dangerous

    Link set · url-anatomy. The real domain is secure-verify.ru; everything left of it is decoration. The most teachable URL here.

  • http://secure-paypa1-verify.com:8080/login.html dangerous

    Link set · phishing-pressure. H1 does not catch this one — it comes from the bundled list, which is how you know layer 2 is wired in.

  • http://127.0.0.2:8080/login.html suspicious

    H4 · url-anatomy. A bare IP with no name to check. Needs the server started with --bind 0.0.0.0.

Must stay silent

The half that decides whether anyone trusts the product. A banner on any of these is a P0 bug.

  • https://www.paypal.com silent

    The genuine brand. The case most likely to regress when H1 is edited.

  • https://mail.google.com silent

    Subdomain of an allowlisted registrable domain.

  • https://www.amazon.com silent

    Confirms arnazon did not poison the real one.

  • https://www.bbc.co.uk silent

    Multi-part TLD. Naive last-two-labels parsing would compare co against the brand list.

  • https://github.com silent

    Ordinary site with no brand signal.

  • https://en.wikipedia.org/wiki/Phishing silent

    Threat vocabulary in the path. You match on host only, so this must not matter.
